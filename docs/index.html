Como funciona

Como a skill conversa com você

Toda skill da CD2 segue os mesmos sete passos. Uma pergunta por vez, sem despejar resposta antes de entender a sua loja.

  1. 1

    Entende quem é você

    Dono, gerente, RH, DP ou financeiro. Uma loja ou uma rede. E em que formato você quer o resultado.

  2. 2

    Oferece puxar os dados

    Se o seu sistema estiver conectado, usa e diz qual usou. Se não, mostra o Archeo e segue com os números digitados.

  3. 3

    Pergunta sobre novidades

    Usa a regra conferida numa data que ela diz, ou pesquisa antes em fontes oficiais. Você escolhe.

  4. 4

    Pede só o que falta

    Com exemplo, valor padrão e o porquê de cada dado, em linguagem de loja.

  5. 5

    Faz a conta no script

    A mesma conta da calculadora, rodada em Python. Nunca de cabeça.

  6. 6

    Entrega com capricho

    Número principal em destaque, semáforo, o que fazer primeiro e o que é só do seu caso. Em página, planilha, WhatsApp ou texto.

  7. 7

    Fecha com a assinatura

    Logo da CD2 Tech, aviso de isenção, o link da calculadora e o nosso contato, se você quiser ir além.

Instalação

Instale onde você já trabalha

O plugin cd2-varejo é o mesmo em todas as plataformas. Muda só a forma de instalar. Depois, é só pedir em português, como você pediria para alguém da equipe.

Marketplace direto do GitHub

Claude Code

Dois comandos dentro de uma sessão. A entrega visual sai como artefato quando o Claude oferece esse recurso e, se não, como arquivo HTML.

/plugin marketplace add cd2tec/cd2-skills
/plugin install cd2-varejo@cd2-skills

Para atualizar: /plugin marketplace update cd2-skills. Para receber versões novas sem pedir, abra /plugin, escolha o marketplace cd2-skills e ligue o auto-update.

Upload do ZIP

Claude Cowork

No app do Claude, a instalação é pelo ZIP da release. Funciona igual ao Claude Code.

Baixar cd2-varejo-claude.zip
  1. Só para você: em Customize > Plugins, faça o upload do ZIP.
  2. Para a organização (Owner, planos Team e Enterprise): em Organization settings > Plugins & skills, clique em Add > Upload a plugin e suba o ZIP.
  3. Na organização, defina quem recebe o plugin em Inventory, no menu da linha do cd2-varejo.

Para atualizar, baixe o ZIP novo e repita o upload no mesmo lugar.

Marketplace direto do GitHub

Codex

Adicione o marketplace e instale o plugin. A entrega visual sai como arquivo HTML, salvo na sua pasta de trabalho.

codex plugin marketplace add cd2tec/cd2-skills
codex plugin add cd2-varejo@cd2-skills

No app do Codex, depois de adicionar o marketplace, você também pode instalar o cd2-varejo pelo diretório de plugins, no marketplace cd2-skills. Para atualizar: codex plugin marketplace upgrade cd2-skills.

Só nos planos de empresa

ChatGPT Work

O ChatGPT Work existe só nos planos de empresa do ChatGPT, e quem instala é o admin do workspace. Ele usa o mesmo pacote do Codex. No ChatGPT Plus ou no gratuito, use a GPT Store.

  1. Em Workspace settings > Plugins, clique em Add e depois em Import marketplace.
  2. Em Source, use https://github.com/cd2tec/cd2-skills. Deixe Path e Branch vazios para acompanhar as atualizações.
  3. Confira se o cd2-varejo veio de plugins/codex/cd2-varejo e defina a política de instalação de cada papel.
  4. As pessoas do workspace instalam em Plugins, na barra lateral.
Developer preview

DeepSeek Harness

O DeepSeek Harness está em developer preview, e a DeepSeek avisa que pode haver mudanças incompatíveis. O pacote traz as skills e um script que copia tudo para a pasta que o DSH lê.

Baixar cd2-varejo-dsh.zip

Descompacte e, na pasta do pacote, rode:

python3 install.py

Instala em ~/.agents/skills. Só para o projeto atual: python3 install.py --project. Para remover: python3 install.py --remove. Detalhes no README do pacote.

ChatGPT Plus e gratuito

GPT Store

Para quem usa o ChatGPT Plus ou o gratuito, cada skill virou um GPT, publicado pela CD2 Tech. Não precisa instalar nada.

  1. Procure na GPT Store por CD2 Escala 6x1, para o fim da escala 6x1.
  2. Procure na GPT Store por CD2 VR/VA: quanto custa, para o custo do vale.

O GPT não se conecta ao seu sistema. Para puxar os dados do ERP, use o plugin no Claude ou no Codex, com o Archeo. Quer saber como os GPTs são montados? Veja o gpts/README.md.
